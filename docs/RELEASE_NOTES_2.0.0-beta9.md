# ConvertZZ 2.0.0-beta9

自 **v2.0.0-beta8** 起的預發行修正。重點是檔案轉換不再損壞 MP3 等二進位檔，並讓篩選器可以選「所有檔案」（回應 #76）。

> 這是預發行版，供測試與回饋。正式版前行為與安裝流程仍可能調整。

## 下載

| 平台 | 建議檔案 |
| --- | --- |
| Windows x64 | `ConvertZZ_2.0.0-beta9_x64-setup.exe`（NSIS；本預發行版不產 MSI） |
| Windows x64（免安裝） | `ConvertZZ_2.0.0-beta9_x64-portable.zip`（解壓即可執行；設定寫在程式目錄） |
| Linux x64 | 優先 `ConvertZZ_2.0.0-beta9_amd64.AppImage`；亦可選 DEB／RPM |

每個發行檔請一併核對隨附的 `SHA256SUMS-*.txt`。Linux 執行相依見 `RUNTIME-DEPENDENCIES-linux-x64.txt`。

使用者**不需要**另外安裝 Node.js、FFmpeg 或 TagLib。

免安裝 zip 內含 `portable` 標記，設定會寫在程式目錄的 `settings-v2.json`，可整包帶走；不支援應用程式內自動更新。

## 相較 beta8 的主要變化

### 檔案轉換：二進位檔不再被寫壞（回應 #76）

- 「內容」與「檔名＋內容」模式遇到 MP3、圖片、壓縮檔等二進位檔時，只略過內容轉換，不再把轉換結果寫回檔案。「檔名＋內容」模式仍會照常轉換檔名。
- 判斷只讀檔案開頭 64 KiB（檔頭格式與 NUL 字元），確認是二進位就不再讀整個檔案，大檔案不會吃掉大量記憶體。
- 純文字檔超過 64 MiB 時略過內容轉換並提示。
- 檔案內容解碼出錯時（包括 UTF-16 長度為奇數或字元不成對）不寫回內容，並提示「解碼時發生錯誤」。
- 只改檔名、內容不變時，同一磁碟區直接改名；跨磁碟區才串流複製並逐塊比對。寫入後的驗證也改成串流逐塊比對，不再把整個檔案讀進記憶體。
- 一次略過多個檔案時，提示合併成「已略過 N 個檔案的內容轉換。」

### 篩選器

- 預設篩選器移除音訊類型（`*.mp3` 等）。舊版的內建預設（包含 1.x 的「音頻文件」與 2.0 早期的「音訊文件」）載入時會自動更新。
- 選檔對話框在「支援的檔案」之後多了「所有檔案」，自訂副檔名但內容是純文字的檔案也能直接選取轉換。
- 設定頁的篩選器編輯器新增「加入所有檔案」，加入後資料夾掃描會收進所有檔案。篩選字串裡自訂的 `*.*` 也會生效。
- 1.0.0.0–1.0.0.3 的舊格式篩選器（例如 `*.txt|*.log|…`，不含 `<`）載入時重設為預設，不再導致資料夾掃描收進所有檔案。
- beta1–beta8 清空篩選器時存下的空字串（當時代表所有檔案），載入時改為預設篩選。需要所有檔案時，請用「加入所有檔案」。
- 若你在預設篩選器後面自己加了音訊或音頻群組，而其他群組與預設相同，載入時會一併換成新預設，自加的音訊群組會被移除。其他自訂篩選維持原樣。

### 資料夾掃描

- 遞迴掃描略過 `.git`、`.svn`、`.hg`、`.bzr` 以及其他以點開頭的資料夾，避免改到版本控制資料。
- 直接選取這類資料夾或其中的檔案時，介面會跳出確認視窗，說明這是版本控制資料夾、轉換可能損壞儲存庫；確認後才處理，取消就從來源清單移除。
- 掃描到 0 個符合篩選器的檔案時會提示，不再默默沒有結果。

### 命令列

- 無頭模式遇到版本控制或點開頭資料夾的路徑時預設略過並印出警告；加上 `--include-ignored` 才處理直接指定的路徑（遞迴掃描一律略過）。
- 無頭模式的篩選器規則與介面一致：`*.*` 代表所有檔案，掃描到 0 個檔案時印出警告。

### 開發流程

- 任何分支推送都會跑 CI，同一個 commit 不會被推送和 PR 各跑一次。
- 發行流程在打包前跑 Rust 測試。

## 已知限制與平台差異

- Linux 選檔對話框的「所有檔案」看不到沒有副檔名的檔案（GTK 對話框限制）。可改用資料夾掃描搭配「加入所有檔案」。

與 beta8 相同的主要限制仍適用：

- Linux **Wayland**：全域快捷鍵與自動複製貼上於本版停用；浮動球置頂依合成器能力而定。
- Linux 托盤通常需要 AppIndicator／StatusNotifier；缺少時主視窗仍可使用。Tauri 在 Linux 不提供托盤左鍵事件，請用選單開啟主視窗。
- ZhConvert API 金鑰優先存入作業系統憑證庫；Linux 缺少 Secret Service 時只保留於目前工作階段。
- 少數字形結果可能與舊版 Windows `LCMapStringEx` 不同。
- 編碼工具改為明確指定編碼，不再跟隨舊版 `Encoding.Default` 系統碼頁。
- 免安裝（portable）套件不支援應用程式內自動更新。
